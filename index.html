プライバシーポリシー

最終更新: 2026年11月24日

本アプリ「MtG Wishlist」（以下「本アプリ」）のプライバシーポリシーです。

収集するデータ

1. 匿名価格データ（自動収集）

本アプリを日本語で使っている場合に、カードを「購入済み」にした際（App Store の国・地域が日本の場合のみ）、およびカードを表示した際に、以下のデータを匿名で開発者のサーバーへ送信します。表示時に送るのはカード印刷 ID と仕上げ種別の 2 つだけで、価格は送信しません（そのカードの価格推移を記録する対象として登録するためのものです）。よく登録されているカードの相場価格を優先して更新するために、登録したカードの種類とアプリのバージョンも送信します。識別子は付いていません。いま登録されているカードの相場価格を更新し続けるために、月に 1 回そのカードの種類を送信します。

本アプリを日本語以外（英語など）で使っている場合は、これらのデータを一切送信しません。

項目内容
カード印刷 IDScryfall のカード印刷識別子（個人情報ではありません）
仕上げ種別foil / nonfoil / etched
希望価格（円）ユーザーが入力した目標購入価格
希望コンディション設定している場合のみ（NM / EX / GD）
フォーマットタグ設定している場合のみ（Standard / Modern 等）

送信しないデータ： 端末 ID・Apple ID・メールアドレス・位置情報・その他いかなる個人情報も送信しません。各送信に識別子を一切付与しないため、同一ユーザーの複数回送信を紐付けることは技術的に不可能です。

2. 使い方の節目（自動収集）

アプリの機能をどこまで使ったかを知るため、次の「節目」に初めて届いたときに、節目の名前とアプリのバージョンだけを匿名で開発者のサーバーへ送信します。同じ節目は端末ごとに 1 回だけ送ります。

節目の例
起動した・翌日以降／7 日以降／30 日以降にまた開いた
カードを追加した・ウィッシュリストが 1〜10 枚のそれぞれに届いた・希望価格を入れた・値下がり通知を設定した・購入を記録した
無料の上限に当たった・Pro の画面を見た・購入のボタンを押した・Pro になった（Pro の画面は、どこから開いたか〔無料の上限・一括登録・購入履歴・ウィジェット〕ごとにも数えます）
デッキの一括登録・共有画像の保存・トークンの表示・購入履歴・バックアップの保存を使った
一覧をリスト表示にした・翌日以降もリスト表示のまま開いた・ホーム画面にウィジェットを置いた
値下がり通知や新しいセットの通知を押してアプリを開いた

送るのは節目の名前とアプリのバージョンだけで、識別子・カード・金額・ウィッシュリストの内容は送りません。どの端末から届いたか、同じ端末の節目どうしを結び付けることは技術的にできません。

また、1 日に何台の端末で使われ、どのくらい続けて使われているかを知るため、アプリを開いた日に 1 回だけ、使い始めてからの日数の区分（当日・1 日目・2〜6 日目・7〜13 日目・14〜29 日目・30 日目以降）とウィッシュリストの枚数の区分（0 枚・1〜4 枚・5 枚以上）を匿名で送信します。サーバーには日付と区分ごとの件数だけが残り、どの端末から届いたかは記録されません。

同じように、1 週間と 1 か月に何台の端末で使われているかを知るため、その週とその月に初めてアプリを開いたときにそれぞれ 1 回だけ、その週またはその月に使い始めたかどうかを匿名で送信します。サーバーには週または月と区分ごとの件数だけが残り、どの端末から届いたかは記録されません。

節目と利用件数には、日本版か海外版か、つまりアプリを日本語で使っているかどうかも添えて送ります。日本語以外で使っている場合も同じように送ります。

3. 友達紹介のコード

この節の内容は、Gift Code を使ったときだけ行われます。

Gift Code で招待コードを受け取ると、開発者のサーバーから、あらかじめ用意した Apple のオファーコードが 1 つアプリへ渡されます。友達がそのコードを使ったときは、友達のアプリが「このコードが使われた」ことだけをサーバーへ知らせます。

サーバーに残るのは、コードと、渡した日時、使われた日時、お礼のコードを渡した日時、受け取ったアプリだけが知っている合言葉です。合言葉はサーバーが作るランダムな文字列です。誰が受け取ったか、誰が使ったかは記録せず、端末やアカウントの識別子も送りません。

配ったコードの控えは、お使いの端末と iCloud キーチェーンに保存され、開発者のサーバーには送られません。無料期間の適用と課金は Apple が行います。

4. 終値の通知

通知を許可している場合、端末の時間帯で毎晩 21 時にウィッシュリストの相場の動きをお知らせするため、次のデータを開発者のサーバーへ送信します。英語で使っている場合も、海外の相場でお知らせするため同じように送信します。

項目内容
通知の宛先Apple が端末とアプリごとに発行するプッシュ通知の宛先
ウィッシュリストのカードカード印刷 ID、仕上げ種別、必要な枚数だけ
言語と版日本語か英語か、日本版か海外版か
通貨円・ドル・ユーロのどれか
時間帯端末の時間帯の名前、例えば Asia/Tokyo
アプリのバージョン送信したアプリのバージョン

カード名、メモ、希望価格、購入の記録、Apple ID、端末 ID は送信しません。サーバーは預かったカードの相場から毎晩お知らせの文を作り、Apple のプッシュ通知サービスを通じて送ります。相場が 1 枚も動かなかった日は送りません。

アプリの中で終値の通知を止めたときは、その場で預けたデータを削除します。iOS の設定で通知の許可をオフにしたときや、ウィッシュリストが空になったときは、次にアプリを開いたときに削除します。アプリを削除した場合は、Apple から宛先が無効になったと返ってきた時点で削除します。

5. 収集しないデータ

本アプリは以下を収集しません。

  • 氏名・住所・連絡先などの個人識別情報
  • 端末識別子（IDFA・IDFV・広告 ID 等）
  • 位置情報
  • ウィッシュリストの内容（カード名・枚数・メモ等。上の節目と 1 日の利用件数で送る枚数の区分と、終値の通知で預かるカードを除く）
  • 閲覧・検索履歴（上の「使い方の節目」は、機能を初めて使ったかどうかだけで、何を見たか・何を検索したかは含みません）

データの利用目的

収集した価格データは、アプリ内で表示する参考価格（国内の実売の値段）の集計と、カードごとの価格推移の記録、よく登録されているカードの件数の集計のための統計的集計にのみ使用します。使い方の節目と 1 日・1 週・1 か月の利用件数は、件数を数えてアプリの改善に役立てるためだけに使用します。友達紹介のコードは、コードを配って使われたかを確かめるためだけに使用します。終値の通知のデータは、お知らせの文を作って送るためだけに使用します。どれも個人識別・広告配信・第三者販売その他の目的には使用しません。

データの保持と削除

価格サンプルデータは収集から 90 日 を超えると集計対象から外れます。集計後の個別サンプルは定期的に削除されます。カードごとの価格推移の記録（1日ごとの集計値。個々の送信や利用者とは結び付きません）は保持します。使い方の節目（節目の名前・アプリのバージョン・受け取った日時のみ）と 1 日・1 週・1 か月の利用件数（日付・週・月と区分ごとの件数のみ）は件数を数えるために保持します。終値の通知のために預かった宛先とカードは、通知をオフにする、ウィッシュリストを空にする、アプリを削除する、のいずれかで削除します。作ったお知らせの文は、送信から 30 日で削除します。

第三者への提供

収集したデータを広告主・データブローカー・その他の第三者には提供しません。サーバー側の集計処理は開発者のみが行います。なお、サーバーには外部のクラウドサービスを使用しています。

また、カードの検索およびカードデータ・画像の取得には第三者サービスの Scryfall API を利用しています。これらのリクエスト（検索語やカードの識別子を含む）は Scryfall に直接送信され、Scryfall のプライバシーポリシーが適用されます。開発者がこの通信内容を受け取ることはありません。
