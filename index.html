プライバシーポリシー

最終更新: 2026年6月27日

本アプリ「MtG Wishlist」（以下「本アプリ」）のプライバシーポリシーです。

収集するデータ

1. 匿名価格データ（自動収集）

カードを「購入済み」にした際、以下のデータを匿名で開発者のサーバー（Supabase）へ送信します。

項目内容
カード印刷 IDScryfall のカード印刷識別子（個人情報ではありません）
仕上げ種別foil / nonfoil / etched
希望価格（円）ユーザーが入力した目標購入価格
希望コンディション設定している場合のみ（NM / EX / GD）
フォーマットタグ設定している場合のみ（Standard / Modern 等）

送信しないデータ： 端末 ID・Apple ID・メールアドレス・位置情報・その他いかなる個人情報も送信しません。各送信に識別子を一切付与しないため、同一ユーザーの複数回送信を紐付けることは技術的に不可能です。

2. 収集しないデータ

本アプリは以下を収集しません。

  • 氏名・住所・連絡先などの個人識別情報
  • 端末識別子（IDFA・IDFV・広告 ID 等）
  • 位置情報
  • ウィッシュリストの内容（カード名・枚数・メモ等）
  • 閲覧・検索履歴

データの利用目的

収集した価格データは、アプリ内の「最安値」参考価格を表示するための統計的集計にのみ使用します。個人識別・広告配信・第三者販売その他の目的には使用しません。

データの保持と削除

価格サンプルデータは収集から 90 日 を超えると集計対象から外れます。集計後の個別サンプルは定期的に削除されます。

第三者への提供

収集したデータを広告主・データブローカー・その他の第三者には提供しません。サーバー側の集計処理は開発者のみが行います。なお、サーバーインフラとして Supabase を使用しており、Supabase のプライバシーポリシーが適用されます。

App Store プライバシー栄養ラベル

Apple の App Store プライバシー申告において、本アプリは以下のように申告しています。

項目内容
収集データその他のデータ（価格情報）
ユーザーへのリンクなし
追跡への使用なし
利用目的アプリ機能（参考価格の集計表示）
