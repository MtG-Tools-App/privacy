プライバシーポリシー

最終更新: 2026年10月20日

本アプリ「MtG Wishlist」（以下「本アプリ」）のプライバシーポリシーです。

収集するデータ

1. 匿名価格データ（自動収集）

本アプリを日本語で使っている場合に、カードを「購入済み」にした際（App Store の国・地域が日本の場合のみ）、およびカードを表示した際に、以下のデータを匿名で開発者のサーバー（Supabase）へ送信します。表示時に送るのはカード印刷 ID と仕上げ種別の 2 つだけで、価格は送信しません（そのカードの価格推移を記録する対象として登録するためのものです）。

本アプリを日本語以外（英語など）で使っている場合は、これらのデータを一切送信しません。

項目内容
カード印刷 IDScryfall のカード印刷識別子（個人情報ではありません）
仕上げ種別foil / nonfoil / etched
希望価格（円）ユーザーが入力した目標購入価格
希望コンディション設定している場合のみ（NM / EX / GD）
フォーマットタグ設定している場合のみ（Standard / Modern 等）

送信しないデータ： 端末 ID・Apple ID・メールアドレス・位置情報・その他いかなる個人情報も送信しません。各送信に識別子を一切付与しないため、同一ユーザーの複数回送信を紐付けることは技術的に不可能です。

2. 使い方の節目（自動収集）

アプリの機能をどこまで使ったかを知るため、次の「節目」に初めて届いたときに、節目の名前とアプリのバージョンだけを匿名で開発者のサーバー（Supabase）へ送信します。同じ節目は端末ごとに 1 回だけ送ります。

節目の例
起動した・翌日以降／7 日以降にまた開いた
カードを追加した・5 枚以上になった・希望価格を入れた・購入を記録した
Pro の画面を見た・Pro になった
デッキの一括登録・共有画像の保存・トークンの表示・購入履歴・バックアップの保存を使った

送るのは節目の名前とアプリのバージョンだけで、識別子・カード・金額・ウィッシュリストの内容は送りません。どの端末から届いたか、同じ端末の節目どうしを結び付けることは技術的にできません。

3. 収集しないデータ

本アプリは以下を収集しません。

  • 氏名・住所・連絡先などの個人識別情報
  • 端末識別子（IDFA・IDFV・広告 ID 等）
  • 位置情報
  • ウィッシュリストの内容（カード名・枚数・メモ等）
  • 閲覧・検索履歴（上の「使い方の節目」は、機能を初めて使ったかどうかだけで、何を見たか・何を検索したかは含みません）

データの利用目的

収集した価格データは、アプリ内で表示する参考価格（国内の実売の値段）の集計と、カードごとの価格推移の記録のための統計的集計にのみ使用します。使い方の節目は、節目ごとの件数を数えてアプリの改善に役立てるためだけに使用します。どちらも個人識別・広告配信・第三者販売その他の目的には使用しません。

データの保持と削除

価格サンプルデータは収集から 90 日 を超えると集計対象から外れます。集計後の個別サンプルは定期的に削除されます。カードごとの価格推移の記録（1日ごとの集計値。個々の送信や利用者とは結び付きません）は保持します。使い方の節目（節目の名前・アプリのバージョン・受け取った日時のみ）は件数を数えるために保持します。

第三者への提供

収集したデータを広告主・データブローカー・その他の第三者には提供しません。サーバー側の集計処理は開発者のみが行います。なお、サーバーインフラとして Supabase を使用しており、Supabase のプライバシーポリシーが適用されます。

また、カードの検索およびカードデータ・画像の取得には第三者サービスの Scryfall API を利用しています。これらのリクエスト（検索語やカードの識別子を含む）は Scryfall に直接送信され、Scryfall のプライバシーポリシーが適用されます。開発者がこの通信内容を受け取ることはありません。

App Store プライバシー栄養ラベル

Apple の App Store プライバシー申告において、本アプリは以下のように申告しています。

項目内容
収集データその他のデータ（価格情報）・使用状況データ（製品の操作＝使い方の節目）
ユーザーへのリンクなし
追跡への使用なし
利用目的アプリ機能（参考価格の集計表示）・分析（使い方の節目）
